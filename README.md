# keyboard.wtf × Alexa+

An experimental Windows desktop companion exposing allowlisted local actions over Model Context Protocol (MCP).

**Status:** implementation in progress. Refer to the `codex/alexa-plus-completion` branch for development changes. This initial default-branch document is not a runnable release.

The original [keyboard.wtf](https://github.com/UnknownGod2011/keyboard.wtf) project is maintained separately and is not modified by this repository.
